Thiết lập API Key

Chỉ lưu trên máy bạn

Dùng API key cá nhân của Gemini, Groq hoặc OpenRouter. Hệ thống sẽ chọn key hợp lệ theo vòng, không vượt giới hạn sử dụng của nhà cung cấp.

Gemini0key đã nhận
Groq0key đã nhận
OpenRouter0key đã nhận
📄 Chọn file .TXT chứa API keyMỗi dòng một key. File tối đa 64 KB. Có thể chứa nhiều nhóm [gemini], [groq], [openrouter].
Key đã tồn tại sẽ không bị thêm trùng. Giữ nguyên các key khác.

Hoặc thêm thủ công

Xem mẫu file TXT
# Một file cho nhiều dịch vụ: [gemini] YOUR_GEMINI_KEY_1 YOUR_GEMINI_KEY_2 [groq] YOUR_GROQ_KEY [openrouter] YOUR_OPENROUTER_KEY

File TXT được đọc trong trình duyệt trên máy bạn, sau đó gửi đến máy chủ cục bộ 127.0.0.1. Key được lưu trong dữ liệu cá nhân của Windows dưới dạng văn bản, không đưa lên GitHub. Không chia sẻ file TXT hoặc file lưu key.

⚙ Chọn model AI

Tự lấy danh sách từ nhà cung cấp

Có API key hợp lệ chưa chắc model mặc định còn được cấp quyền. Hãy chọn dịch vụ, lấy danh sách model mà API cho phép, bấm kiểm tra và lưu. Model sẽ được nhớ cho các lần tạo video tiếp theo.

Đang tải cấu hình model…

Mỗi nhà cung cấp có giới hạn và quyền model khác nhau. Danh sách có thể chứa model trả phí.

Thử model sẽ gửi một câu hỏi rất ngắn và có thể tính vào hạn mức API. Việc lấy danh sách thành công không bảo đảm mọi key trong pool đều dùng được model đó. Nếu gặp HTTP 404, hãy chọn model khác trong danh sách và thử lại.
